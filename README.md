## 极速型NAS是什么，和通用型差在哪

## 买之前先确认的三件事

极速型有几条限制只写在文档里，下单前不看，容易买了用不上。

**协议**：极速型仅支持 NFS。Linux 环境没问题，Windows 客户端要 SMB 共享的场景它覆盖不了，对应产品是通用型。买错档位再迁移数据，比单价贵几毛钱麻烦多了。

**地域**：极速型的开放地域比通用型少，而且文件系统必须和挂载它的 ECS、容器在同一个地域、同一个 VPC 内网。先确认你的计算资源所在地域有没有开通，再谈计费方式。

**预付费的弹性**：包年包月扩容要补差价，反向缩容基本没有通道。容量规划宁留余量，也别为了单价好看把规格顶死。

## 冷数据图便宜：云 NAS 和自建 NAS 怎么比

单看大容量存储的单价，自己攒一台 NAS 便宜得多，但便宜只在数据冷、访问少的前提下成立。自建的一次性投入并不高：中端四盘位成品机（Synology、QNAP 这类品牌为主）不带盘普遍 400–700 美元，硬盘每块 60–400 美元；有海外测评算过一笔账，40TB 数据自建 NAS 十年总成本约 1,750 美元。

同样的 40TB 放通用型容量型，按 0.15 元/GiB/月 算，每月约 6,100 元，一年 7 万多，十年 70 多万——就算用上资源包和折扣，数量级也压不下来。

反过来说，自建 NAS 给不了微秒级延迟，也进不了你云上 VPC 的内网。数据要被几十台 ECS、容器或训练任务高频读写时，跨公网访问家里的 NAS，延迟和带宽都撑不住。所以这道题的答案很清晰：算力在云上、数据热，用云 NAS；数据冷、只在本地用，自建或直接用更便宜的对象存储 OSS。

## 常见问题

**内网读写流量要另外收费吗？**
不用。极速型面向 VPC 内网使用，同地域内网挂载的读写流量不单独计费，费用集中在存储容量上。通用型如果通过公网访问，读流量会单独计费，这是两者计费结构的一个区别。

**按量付费会不会突然产生大额账单？**
费用跟实际存储量线性相关：存 1TB 就按 1TB 的单价出账，释放文件系统后停止计费。按账期从账户余额扣费，保持余额充足即可。

**包年包月买小了怎么办？**
控制台支持对文件系统扩容，补差价即可；缩容没有通道。这也是前面建议规格宁留余量的原因。
